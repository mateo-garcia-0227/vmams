# VMAMS Tool
## Overview
This tool represents one component of my thesis work while being a graduate student in the MS ECE program at *Purdue University Northwest (PNW)*. 
The goal was to facilitate student education in the *Computer Organization & Design* course. 
The result of my work is the **Visualization of Microarchitecture and Microarchitecture Security (VMAMS)** tool, powered by *Unity* gaming engine. 
As the name suggests, VMAMS was developed with an emphasis on possessing strong visualization capabilities, enabling students to observe what is occuring within the CPU at the register/memory level.
Key concepts covered in the tool (presented as individual learning modules) include the ARM ISA LDR and STR **Memory Access** instructions, 
CPU **Pipelining**, and the **[Spectre](https://spectreattack.com/spectre.pdf)** attack.

Please note this repository currently contains only the final build of the Unity project and additional files required to run the executable. 
I am not yet making the tool open-source because it is still a work-in-progress, with another PNW student continuing my work. 

## How-To Use
I have uploaded a zip folder containing the *VMAMS.exe*, *UnityPlayer.dll*, and *UnityCrashHandler64.exe* files. 
To use my tool, simply unzip the folder and run the *VMAMS.exe* file. **All 3 files must be present in the same file location for the Unity application to run properly.**
